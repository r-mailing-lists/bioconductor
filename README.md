# bioconductor

Bioconductor help and discussion

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/bioconductor/](https://stat.ethz.ch/pipermail/bioconductor/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics

## Viewer

Browse these archives at [archives.rstats.dev](https://archives.rstats.dev/lists/bioconductor/)
